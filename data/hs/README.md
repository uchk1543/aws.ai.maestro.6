# data/hs/ HS부호 표 (담당: 검증)
- 관세청 HS부호 자료를 받아 CSV로 둔다 (A6). 출처와 받은 날짜를 이 파일에 적는다.
- tools/hs.py의 HSTable이 이 파일을 읽는다 (search, under, exists).

## 출처
- 자료: 관세청_HS부호_20260101 (2026-01-01 기준)
- 주소: https://www.data.go.kr/data/15049722/fileData.do (공공데이터포털 15049722)
- 제공: 관세청. 공공저작물 출처표시(제1유형)이므로 출처를 밝히면 쓸 수 있다.
- 받은 날짜: 2026-11-19 (refs/sources.csv 기록)

## hs_codes.csv
- 인코딩 UTF-8, 줄바꿈 LF, 머리글 한 줄 + 11,327줄.
- 열:

| 열 | 뜻 | 원본 열 |
|---|---|---|
| hsk | 10자리 HSK 부호 (문자열, 앞 0 유지) | HS부호 |
| name_ko | 한글 품목명 | 한글품목명 |
| name_en | 영문 품목명 | 영문품목명 |
| qty_unit | 수량 단위 코드 (없으면 빈칸) | 수량단위코드 |
| weight_unit | 중량 단위 코드 (없으면 빈칸) | 중량단위코드 |

## 만든 방법
- 원본 xlsx(12,469줄)는 저장소에 올리지 않는다. refs/ 아래에 두고(.gitignore 대상) 받는다.
- 10자리가 아닌 줄(7~9자리, 1,142줄)은 상위 구분 줄이라 뺐다. 10자리 줄만 남겼다.
- 품목명 안의 줄바꿈과 앞뒤·겹친 공백은 한 칸 공백으로 정리했다.
- 적용 시작·종료일 열은 넣지 않았다. 원본의 적용 종료일이 모두 2026-12-31이다. 새 기준 자료를 받을 때 다시 정한다.
- 이 표는 2026-12-31까지 유효하다. 다음 해 자료가 나오면 같은 방법으로 바꾼다.
